# Qutes language reference

Use this reference when you need to know what a Qutes expression returns or how it changes a program. If you are writing your first circuit, the [interactive tutorial](https://qutes-lang.web.app/tutorial.html) walks you through one experiment at a time.

## Measurements and results

[Measuring a quantum value](reference/measurement.md) covers the `measure` expression, its return types, and what happens to a qubit or register after it is measured.

## Run an example

Open the [playground](https://qutes-lang.web.app/play.html) to edit and run a program in your browser. For local development, the [Downloads page](https://qutes-lang.web.app/downloads.html) offers the VS Code extension and the command-line compiler.
