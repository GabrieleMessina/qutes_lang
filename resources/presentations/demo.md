# A 90-second Qutes demonstration

0–20 seconds. Open the Bell pair. Read the helper aloud. Ask the audience which pairs will appear. Run the program and show the matching results.

20–45 seconds. Add `not(bob);` before the return. Ask for a second prediction and run again. Point to the two different outcomes. Download the project to continue locally.

45–70 seconds. Open wire reuse with its shipped configuration. Show twelve loop iterations, 39 logical qubits, and six physical wires. The compiler cleans the temporary before reusing its storage.

70–90 seconds. Show Teach for the class exercise, Build for the local project, and Inspect for the reproducible Qiskit notebook. Credit Simone Faro, Francesco Pio Marino, and Gabriele Messina.
