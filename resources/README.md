# Qutes in practice

Use Python 3.12 or 3.13. From the repository root run `python -m pip install ".[backend]"` in a virtual environment.

| Choose a path | First experiment |
| --- | --- |
| [Teach](lessons/bell.md) | Predict two measurements, flip one bit, and explain the correlation. |
| [Build locally](starters/README.md) | Run the canonical Bell program and take an edited program into the CLI. |
| [Inspect in Qiskit](notebooks/correlations.ipynb) | Build a circuit, change a static input, and compare the decoded outcomes. |
| [Present Qutes](presentations/intro.html) | Open the slide deck in a browser. Use the [demo script](presentations/demo.md) and [captions](presentations/demo.vtt). |

The release bundle includes the examples, their configuration, the notebook and the compiler wheel. The [language tour](../examples/language/README.md) covers the complete local collection.
