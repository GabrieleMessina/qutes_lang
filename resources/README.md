# Qutes in practice

Use the [portable CLI](https://github.com/GabrieleMessina/qutes_lang/releases/tag/2.0.0) to run a Qutes program offline. To run the notebook from a source checkout, use Python 3.12 or 3.13 and install `python -m pip install ".[backend]"` from the repository root in a virtual environment.

| Choose a path | First experiment |
| --- | --- |
| [Teach](lessons/bell.md) | Predict two measurements, flip one bit, and explain the correlation. |
| [Build locally](../tools/portable/QUICKSTART.md) | Run the Bell program included in your platform download and use the CLI in your own project. |
| [Inspect in Qiskit](notebooks/correlations.ipynb) | Build a circuit, change a static input, and compare the decoded outcomes. |
| [Present Qutes](presentations/intro.html) | Open the slide deck in a browser. Use the [demo script](presentations/demo.md) and [captions](presentations/demo.vtt). |

The [Catania study collection](lessons/catania/README.md) pairs 17 syllabus chapters with runnable experiments and three optional extensions.

The [language tour](../examples/language/README.md) covers the complete example collection in this repository.
