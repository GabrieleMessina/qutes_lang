# Quantum Computer Programming · Catania

Original English study materials for the University of Catania L-31 course, 2026–27. See the [official syllabus](https://web.dmi.unict.it/corsi/l-31/insegnamenti?seuid=F98F71EC-0839-4BC8-BDB7-0CA2B1F0D47E).

Open [the chapter and lab text](course.json) or run the [Grover experiment](programs/grover.qut) from the repository root:

```sh
qutes run resources/lessons/tutorial/programs/grover.qut
```

Tuple fields follow the Qutes return expression. Binary labels in the lessons use high bit first; false is 0 and true is 1. Each experiment has settings near the top. Predict an outcome before editing and rerunning. The website renders the same sources and exposes their standalone Qiskit exports.
